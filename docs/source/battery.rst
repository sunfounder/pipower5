Akku
=================

.. image:: img/vh2pin_battery.png
    :width: 400
    :align: center

.. raw:: html

   <br/>

* **VCC**: Pluspol des Akkus.
* **GND**: Minuspol des Akkus.

Dies ist ein von SunFounder hergestellter, spezieller Akkupack, bestehend aus zwei 18650-Akkus mit einer Kapazität von 2000mAh. Der Anschluss ist VH3.96 2P, der nach dem Einstecken in das Shield direkt geladen werden kann.

**Merkmale**

* **Zusammensetzung**: Li-Ion
* **Akkukapazität**: 2000mAh, 14,8Wh
* **Akku-Gewicht**: 90,8g
* **Anzahl der Zellen**: 2
* **Anschluss**: VH3.96 2-polig
* **Tiefentladeschutz**: 6,0V

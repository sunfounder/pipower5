バッテリー
=================

.. image:: img/vh2pin_battery.png
    :width: 400
    :align: center

.. raw:: html

   <br/>

* **VCC**: バッテリーのプラス端子。
* **GND**: バッテリーのマイナス端子。

これは SunFounder 製のカスタムバッテリーパックで、容量 2000mAh の 18650 バッテリー 2 本で構成されています。コネクターは VH3.96 2P で、シールドに挿入後直接充電できます。

**仕様**

* **構成**: Li-ion
* **バッテリー容量**: 2000mAh、14.8Wh
* **バッテリー重量**: 90.8g
* **セル数**: 2
* **コネクター**: VH3.96 2ピン
* **過放電保護**: 6.0V

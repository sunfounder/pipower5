## 关于此套件：

文档：https://docs.sunfounder.com/projects/pipower5/en/latest/

PiPower 5 是一款多功能 UPS 解决方案，专为与 Raspberry Pi 设备无缝集成而设计。它具有强大的电源路径管理、双锂电池充放电能力，以及防反接、过充和过放等基本保护功能。
